# 계정과 계획 도구

로비의 **내 계정 · 캐릭터 관리**에서 실제 게임 계정의 보유 여부, E0~E6, 전용 광추 미보유/S1~S5를 입력합니다. 워프 시뮬레이터 도감과 별도로 프로필의 `account` 영역에 저장합니다. 파티의 보유 필터와 아케론 E2 조건에 반영하며, 광추 조건이 있는 공략은 미보유 경고를 표시합니다. 성혼·중첩별 전체 DPS 계산은 제공하지 않습니다.

프로필 관리에는 이름 변경, 현재 데이터 용량, 백업/복구, 삭제가 있습니다. 이름 변경은 새 프로필 저장을 먼저 완료하고 이전 이름을 정리합니다. 기존 이름을 덮어쓰지 않습니다. 백업 파일에는 실제 계정도 포함하며, 과거 세 영역 백업을 가져오면 실제 계정 영역은 빈 상태로 시작합니다. 마지막 내보내기 또는 생성 후 30일이 지나면 로비에 백업 알림을 표시합니다. 다운로드 시작 시점을 기록하며 다운로드 파일의 보관 여부를 확인할 수는 없습니다.

유물 계산기 하단에서 현재 입력 또는 저장된 같은 캐릭터·평가 방식의 A/B를 비교합니다. B − A 변화량과 A의 목표·가중치로 평가한 점수를 표시합니다. 속도 도우미는 첫 사이클 150 AV + 이후 사이클당 100 AV, 지속 속도 버프, 시작 시 한 번의 행동 당김을 모델링합니다. 지원 캐릭터를 선택하고 실제 효과 수치를 입력하세요. 반복 행동 당김과 동적 버프는 모델링하지 않습니다.

픽업 준비 계산기에서 남은 일수, 일일 훈련, 월정액 수령 가능 일수, 예상 이벤트·기타 보상을 설정합니다. 예상 재화를 포함할지 선택할 수 있습니다. 결과 카드에는 50/75/90/95% 성공 비용, 천장 보장 비용과 각각의 부족분을 표시합니다.

공유 링크는 URL fragment에 compact tuples와 deflate 압축으로 저장합니다. 지원하지 않는 브라우저는 compact JSON 인코딩을 사용합니다. 뽑기 링크는 선택한 목표의 현재/목표 돌파·중첩과 천장·확정 정보만, 유물 링크는 캐릭터 ID와 목표·조건만 포함합니다. 프로필, 실제 계정 보유 목록, 재화, 능력치, 기록과 세이브는 읽거나 포함하지 않습니다. 공유받은 계획은 사용자가 **계산기에 열기**를 눌러야 적용되며 개인 저장을 덮어쓰지 않습니다.

PWA는 HTTPS 또는 localhost에서 동작합니다. 설치 가능한 브라우저에는 로비의 앱 설치 버튼을 표시합니다. 서비스 워커 설치가 완료된 뒤 앱 기본 화면, 계산 로직, 카탈로그, 캐릭터/광추 미리보기와 운명의 길 아이콘을 오프라인으로 제공합니다. 대형 워프 일러스트, 음성, 음악, 외부 폰트, 원문 PDF는 오프라인 캐시에 포함하지 않습니다. 새 버전은 기존 앱 창을 모두 닫고 다시 열면 적용됩니다.

`npm run build`는 캐시 파일 목록과 콘텐츠 해시를 생성하고 `dist/`에 manifest와 서비스 워커를 포함합니다. 배포 주소가 달라지면 `index.html`의 절대 OG 이미지 주소도 변경하세요. 로비의 배너/세팅 버전과 출처 확인 날짜는 수록 파일 기준이며 현재 라이브 게임 버전을 자동 조회하지 않습니다.

검증: `npm test`. `scripts/verify-planner-tools.mjs`는 계정 E/S, 프로필 이동·충돌, 알림, 예상 재화, 속도 경계, 비교 기준, 공유 링크 복원 및 개인정보 제외를 검사합니다.
