# 워프 BGM — 네온 체이스

`assets/audio/starlit-orbit.wav`에 직접 합성한 오리지널 전자 인스트루멘털 BGM을 포함했다. 160 BPM의 하프타임 비트에 포화감 있는 서브베이스, 엇박 킥, 스네어, 빠른 하이햇과 짧은 네온 신스 아르페지오를 더했다. 단조 패드와 상승 효과음은 우주 분위기를 유지하며, 보컬과 랩은 없다. 24초 비트 구간을 반복하고 마지막 5초는 부드럽게 마무리한다. 외부 음원 서비스나 다운로드가 필요하지 않다.

3·4·5성 모두 워프 시작 버튼을 누르는 순간 오디오를 준비하고 상승 화음과 낮은 리듬이 바로 나온다. 로비에서 기본 음원을 미리 내려받아 준비되는 대로 메인 BGM이 이어진다. 신호 클릭을 기다리는 동안도 음악이 유지되며 24초 구간을 반복한다. 포털 개방 순간에는 음악을 재시작하지 않고 낮은 충격음과 반짝이는 화음을 더하고, 반복을 해제해 결과 화면에서 자연스럽게 끝난다. 움직임 줄이기 설정에서도 시작 시점에 재생된다.

워프 시작·신호 개방 클릭에는 짧은 전자 효과음, 결과 넘김과 워프 중 버튼 클릭에는 작은 벨 효과음이 나온다. 효과음도 같은 음소거·볼륨 설정을 따른다.

BGM ON/OFF와 볼륨은 저장된다. ON/OFF는 배경음악과 효과음을 제어하며 캐릭터 음성은 별도로 재생한다. 볼륨은 모든 오디오에 적용된다. 스킵 시 BGM을 중지한다. 결과 요약 화면에서는 음성을 재생하지 않으며 재생 중인 대사도 중단한다. 로비 복귀·새 워프·탭 숨김은 재생을 중지한다. 음원을 제때 불러오지 못하면 같은 분위기의 Web Audio 인스트루멘털로 대체하고, 뒤늦게 음원을 교체하지 않는다.

5성 캐릭터 공개 시 `warp-voice-lines.js`에 연결된 실제 게임 한국어 대사를 한 번 재생한다. 대사 중에는 BGM을 낮추고 끝나면 복원한다. 음원 출처와 캐릭터별 연결은 [음성 설명](../assets/audio/voices/README.md)에 기록했다.

`warp-music-tracks.js`의 `default`에서 기본 음원을 지정한다. 캐릭터 ID별 `characters`, 속성별 `elements` 설정이 기본 음원보다 우선한다. 기존 `dropOffset` 값은 이제 워프 시작 시 재생할 음원 내부의 초 단위 위치로 사용한다. 반복 구간은 이 위치부터 끝나기 5초 전까지다. 정적 웹 서버에서 `assets/audio/`도 함께 제공해야 한다.

음원은 `assets/audio/build-warp-bgm.ps1`로 재생성할 수 있다. 24 kHz 스테레오 PCM WAV이며 끝부분은 자연스럽게 페이드아웃된다.
