# Character catalog

Source: https://github.com/Mar-7th/StarRailRes
Korean index: https://raw.githubusercontent.com/Mar-7th/StarRailRes/master/index_new/kr/characters.json

Imported entries: 98 (75 five-star and 23 four-star entries, including alternate forms).
The ten Trailblazer entries use readable male/female names and path/element labels.
`assets/js/characters.js` is loaded directly by `index.html`. Original data is in `assets/data/characters-source.json`; previews are in `assets/characters/`.
Character inventory keys use IDs to distinguish characters with the same name and different paths.
The full collection catalog is independent of the existing event warp pools.
Full-size character illustrations for collection zoom and 4/5-star warp reveals are stored under `assets/character-art/`. Failed or slow full-size loads fall back to the preview.
Pearl (1503) is the featured character. Alternative forms retain separate inventory IDs.
