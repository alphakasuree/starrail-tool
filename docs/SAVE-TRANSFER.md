# 로컬 세이브 파일 이동

로비 상단의 **세이브 내보내기·가져오기**에서 현재 아이디의 데이터를 JSON 파일로 내려받습니다. 다른 기기에서 사이트에 접속하고 저장용 아이디를 입력한 다음, 같은 메뉴에서 파일을 선택해 미리보기를 확인하고 가져옵니다. 원래 파일과 다른 아이디에도 가져올 수 있습니다. 서버 전송은 없습니다.

파일에는 워프 기록, 캐릭터·광추·콜라보 천장과 확정, 픽업 선택, 보유 목록, 저장한 유물 세팅과 파티가 포함됩니다. 저장하지 않은 편집 내용과 픽업 준비 계산기의 계획은 포함되지 않습니다. 가져오기는 현재 아이디의 세 영역 전체를 교체하며 병합하지 않습니다. 가져오기 전 세이브는 현재 브라우저에 보관하고, 같은 메뉴에서 한 번 되돌릴 수 있습니다. 이후 다시 가져오면 가장 최근 가져오기 직전의 세이브로 교체됩니다.

파일 형식은 `format: "honkai-local-save"`, `version: 1`, `profileId`, `exportedAt`, `sections: {warp, relic, teams}`입니다. 세 영역은 기존 저장 객체·배열 또는 `null`입니다. 최대 파일 크기는 512KB입니다. 파일 형식, 버전, 전체 구조, 천장 범위, 기록 날짜, 유물 수치와 파티 형태를 검사한 뒤 적용합니다.

기존 `honkai-id-v1:<아이디>:warp|relic|teams` 키는 계속 읽습니다. 가져온 뒤에는 `honkai-id-v1:<아이디>:save-bundle` 한 키에 세 영역과 직전 세이브를 함께 저장합니다. 이후 저장도 이 묶음을 갱신합니다. 가져오기와 되돌리기는 각각 단일 `localStorage.setItem`으로 적용해 저장 공간 부족 시 일부 영역만 교체되지 않도록 합니다. 미리보기 후 저장 내용이 바뀌면 파일을 다시 선택해야 합니다.

검증: `node scripts/verify-save-transfer.mjs`.

기존 큰 세이브도 내보내 백업할 수 있지만 가져오기는 512KB까지 가능합니다. 세이브 관리에서 복구 사본만 지우거나, 이름을 입력해 현재 프로필의 저장과 복구 사본을 삭제할 수 있습니다. 다른 프로필은 유지됩니다.
