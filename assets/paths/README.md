# 운명의 길 문양

[StarRailRes](https://github.com/Mar-7th/StarRailRes/tree/master/icon/path)의 게임 운명의 길 문양을 사용한다. 원저작자는 HoYoverse / COGNOSPHERE다. 5성 공개 시 해당 운명의 길 문양과 한국어 이름을 먼저 표시하며, 1.45초 후 일러스트와 캐릭터 음성을 공개한다. 문양 단계에서 클릭하면 해당 결과를 바로 공개하고, 스킵·요약·워프 복귀 시 대기 중인 공개를 취소한다. 움직임 줄이기 설정에서는 모션 없이 0.45초 동안 표시한다.
