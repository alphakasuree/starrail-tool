# 실제 한국어 캐릭터 음성

시뮬레이터에 포함된 개척자 이외의 5성 캐릭터 65명에게 실제 게임 한국어 음원 한 개씩 연결했다. 합성 음성이나 성우 모방 음성은 사용하지 않는다. 등장 대사 자막은 표시하지 않는다.

출처: [StarRail Voice](https://huggingface.co/datasets/simon3000/starrail-voice), [제작·추출 설명](https://github.com/simon300000/starrail-voice). 음원 원저작자는 HoYoverse / COGNOSPHERE이며 워프용 오리지널 BGM과는 별개다. 사용한 데이터셋은 4.4.0 버전이다.

`sources.json`에 캐릭터 ID·이름·화자·데이터셋 행 번호·원본 게임 파일명·언어·출처·파일 크기를 기록했다. 음원은 로컬 WAV로 제공하며 언어와 화자, WAV 구조를 확인했다. 데이터셋의 전사 텍스트는 출처 기록용이며 화면 자막으로 사용하지 않는다.

로빈·서머레토(1512), 어벤츄린·웨이브(1513)는 해당 형태의 음원이 이 데이터셋에 없어 각각 기본 로빈(1309), 어벤츄린(1304)의 실제 한국어 음원을 공유한다. `sources.json`의 `sharedFrom`으로 표시했다.

워프 시작 때 필요한 음원을 미리 불러오고, 5성 캐릭터 공개 때 한 번 재생한다. 음성 중에는 BGM을 낮춘다. 10회 워프를 스킵해 결과 요약으로 이동하면 음성을 재생하지 않는다. 요약 진입 시 재생 중이거나 로딩 중인 대사도 취소한다. 다음 결과·로비 복귀·새 워프·탭 숨김 시에는 이전 음성을 중단한다. 광추와 3·4성 결과에는 대사를 재생하지 않는다.

BGM ON/OFF는 배경음악과 효과음에 적용하고 캐릭터 음성은 별도로 재생한다. 볼륨 슬라이더는 전체 오디오에 적용한다. Web Audio의 파일 불러오기나 디코딩이 실패하면 HTML Audio 재생으로 다시 시도한다.
